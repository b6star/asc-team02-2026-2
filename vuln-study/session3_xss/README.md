# Session 3 · Cross-Site Scripting

- **반사형 XSS(Reflected Cross-Site Scripting):** 요청에 포함된 입력값이 응답에 그대로 반영되고 브라우저에서 스크립트로 실행되는 취약점이다.
- **저장형 XSS(Stored Cross-Site Scripting):** 서버에 저장된 악성 입력이 다른 사용자의 화면에 표시될 때 스크립트로 실행되는 취약점이다.
- **DOM 기반 XSS(Document Object Model-based Cross-Site Scripting):** 브라우저의 JavaScript가 신뢰할 수 없는 입력을 위험한 DOM 출력 지점에 전달해 발생한다.
