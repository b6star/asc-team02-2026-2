01 · 서비스 소개

고객 문의와 첨부파일을 관리하는 서비스

고객은 문의를 등록하고, 고객지원팀은 답변과 파일 공유를 처리한다.

고객 화면

문의 접수제목, 문의 내용, 확인이 필요한 이미지를 등록한다.
내 문의접수한 문의의 번호와 처리 상태, 고객지원팀 답변을 확인한다.
첨부파일 교체답변 대기 중인 문의는 첨부 이미지를 다시 올릴 수 있다.

운영 기능과 용어

Ticket문의 내용, 작성자, 상태, 첨부파일을 묶어 저장한 문의 한 건.
Internal Ticket고객에게 보이지 않는 사내 업무 요청.
Admin Bot관리자 세션으로 업로드된 파일을 열어 검토한다.
Export첨부파일을 외부에 공유하기 위한 기능. 파일을 Export Job으로 복사하며, 처음에는 private, 공유를 켜면 외부에서 열 수 있는 shared 링크가 생긴다.
실습 목표: 일반 고객 계정에서 시작해 내부 티켓의 production-backup.txt를 공유 링크로 열고 FLAG를 확인한다.

왜 403인가

첨부파일 조회 API는 사용자 역할과 Workspace를 검사한다. 고객은 public, 백업 파일은 internal이므로 거부.

if user.role != 'admin' and attachment.workspace != user.workspace: return 403

IDOR로 메타데이터는 얻었지만 파일 내용까지 직접 읽을 수는 없다.

다음 단서: 07229번 티켓의 답변에 운영 도구의 Export API와 프런트엔드 디버그 파일이 남아 있다고 적혀 있다.

08 · SVG 준비

관리자 브라우저가 보낼 요청 작성

생성된 Job ID를 Share API에 넣고, SVG가 열릴 때 자동 전송하도록 만든다.

malicious.svg

이 요청이 필요한 이유

POST /api/admin/exports/JOB_ID/share Content-Type: application/x-www-form-urlencoded enabled=true

Share API는 관리자 역할을 검사한다. 고객 세션으로 직접 호출하면 403.

대신 관리자 봇이 SVG를 열면 관리자 세션 쿠키가 같은 출처의 Share 요청에 자동 첨부된다.

CSRF: 서버는 관리자 권한은 확인하지만, 그 관리자가 의도해서 보낸 요청인지 확인하지 않는다.

10 · CSRF 결과

private 상태가 shared로 변경

관리자 봇의 요청으로 서버 상태는 바뀌지만 응답은 봇 브라우저로 돌아간다.

요청 흐름

1. GET /bot-login?token=... 2. GET /files/<svg-id> 3. SVG onload 실행 4. POST /api/admin/exports/<job-id>/share Cookie: session=admin enabled=true

Share 응답과 공개 URL은 관리자 봇 브라우저로 돌아가므로 공격자는 아직 URL을 모른다.

Export Job

Job ID아직 생성되지 않음Status-Public URL-
private→shared

서버에는 shared 상태와 토큰이 저장된다. 공격자는 다음 단계에서 자신이 만든 Export를 다시 조회한다.

서버가 놓친 검사: CSRF 토큰 또는 Origin 검증. 관리자 권한만으로는 요청 의도를 확인할 수 없다.

12 · 정리

취약점별 방어 방법

IDOR

티켓 조회

확인 코드와 티켓 소유권을 서버에서 검증. 내부 티켓은 고객 API 응답에서 제외.

ticket.owner_id == current_user.id
BFLA

Export 생성

관리자 기능의 모든 진입점에서 역할 검사. URL이나 메뉴 이름에 의존하지 않는다.

@admin_required def create_export(...)
CSRF

외부 공유

  1. 업로드 파일을 별도 Origin에서 제공
  2. SVG 스크립트 제거 또는 안전한 이미지로 변환
  3. 상태 변경 API에 CSRF 토큰 검증 추가
  4. 관리자 봇의 접근 권한과 경로 제한
연계 관계: IDOR가 첨부파일 ID를 노출하고, BFLA가 파일을 Export로 복사하며, CSRF가 관리자 권한으로 외부 공유를 켠다.
